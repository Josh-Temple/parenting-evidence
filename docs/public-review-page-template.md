# 根拠を詳しく見る

## Review scope

- Population
- Intervention / exposure
- Comparator
- Outcomes
- Time horizon

## 主な研究

研究ごとに:
- study / review
- design
- N
- population
- result
- limitation
- Japan applicability

## Search method

- search mode
- anchor reviews
- search date
- databases / sources
- queries
- inclusion / exclusion
- known limitations

独自systematic searchをしていない場合、その旨を明記する。

## Evidence limitations

- bias
- confounding
- imprecision
- heterogeneity
- indirectness
- component attribution
- missing safety data

該当するものだけ。

## 日本の家庭への適用

- Japan-specific evidence
- cultural / healthcare / childcare differences
- unknown directness
