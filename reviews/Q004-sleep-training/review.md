# 睡眠トレーニングには効果があり、長期的な悪影響はあるか

Status: PUBLISHED  
Last searched: 2026-09-23  
Last source verification: 2026-09-23

## 30秒で分かる結論

生後6か月以降で、寝つきや夜間覚醒が家族の負担になっている場合、行動的な睡眠介入には**短期的に寝つきや夜間覚醒を改善する根拠があります**。ただし「睡眠トレーニング」は一つの方法ではなく、graduated extinction、bedtime fading、camping out、就寝ルーティンなどをまとめた呼び方です。

一方、乳児の総睡眠時間が何時間も増えるとは限りません。0〜5歳のRCTをまとめたメタ分析では、夜間睡眠時間の平均増加は約9分/夜でした。改善は「早く寝つく」「長く連続して眠る」「親が睡眠を問題と感じにくくなる」といった形で現れることがあります。

長期的な害については、小規模RCTと5年追跡研究で、情緒・行動、愛着、親子関係などの悪化は確認されていません。ただし、研究数は多くなく、「どの方法でも害がない」と証明されたわけではありません。

6か月未満は研究結果が一致しておらず、6か月以降と同じ効果が確立しているとは言えません。このReviewでは6か月以降の結果をそのまま当てはめません。

また、**睡眠トレーニングと安全な睡眠環境は別問題です。** 1歳未満では、こども家庭庁が示す「あおむけに寝かせる」などの安全指針を優先します。

## 「睡眠トレーニング」は一つの方法ではない

日常語では、泣いてもすぐに対応しない方法をまとめて「睡眠トレーニング」と呼ぶことがあります。

研究では、かなり異なる方法が含まれます。

- graduated extinction: 少しずつ待つ時間を調整しながら確認する
- bedtime fading: 眠りやすい時刻にいったん就寝時刻を合わせ、徐々に調整する
- camping out: 親が近くにいながら、徐々に介入を減らす
- checking-in: 一定間隔で短く確認する
- consistent bedtime routine: 毎晩の流れを一定にする
- broader parent education: 睡眠環境や寝かしつけ行動をまとめて見直す

したがって、「睡眠トレーニングは効くか」という問いだけでは粗く、どの方法・年齢・アウトカムかを見る必要があります。

## 生後6か月以降では、短期的な改善が期待できる

2020年のsystematic reviewでは、乳児の睡眠問題に対する12の介入研究を採用し、ルーティンやcontrolled cryingを含む5つの行動的介入で短期的な改善が報告されました。

このレビューは、**生後6か月を超えた乳児の行動性睡眠問題では、行動的介入は有望**としています。

2025年のより新しいsystematic review / meta-analysisでも、20研究をまとめ、夜間覚醒やcry/fuss behaviorなどに全体として小〜中程度の改善があると整理しています。

ただし、研究ごとに方法が違い、「この一つの方法が最も優れている」とは言えません。

## 「長く眠る」と「起きにくくなる」は別

睡眠介入の効果を見るとき、「睡眠時間」だけを見ると実態を見落とします。

2021年に32件のRCTをまとめたメタ分析では、夜間睡眠時間は介入群で平均約9分長くなりました。

これは統計的には差がありますが、

> 睡眠トレーニングをすると何時間も長く眠る

というイメージとはかなり違います。

一方、2024年のactigraphyを使った研究のsystematic reviewでは、

- 夜間覚醒の回数
- 入眠までの時間

には比較的一貫した改善がありました。

2025年のデジタル睡眠介入のメタ分析でも、最長の連続睡眠時間は伸びましたが、総夜間睡眠時間は明確には増えませんでした。

つまり、睡眠介入の価値は「総睡眠時間を増やす」だけではなく、**寝つき・睡眠のまとまり・家族が対応する回数**などに現れる可能性があります。

## 泣かせるとコルチゾールが上がるのか

2016年のRCTでは、生後6〜16か月の43人を、

- graduated extinction
- bedtime fading
- sleep education

に無作為に分けました。

graduated extinctionとbedtime fadingでは入眠までの時間が改善し、graduated extinctionでは夜間覚醒なども改善しました。

同時に測定した唾液コルチゾールは、介入群で対照群より増えるのではなく、小〜中程度低下しました。

この研究からは、

> graduated extinctionを行うと必ず乳児の生理的ストレスが高まる

とは言えません。

ただし43人という小さな研究です。あらゆる方法・家庭についてストレス影響がないことを証明したわけではありません。

## 愛着や情緒発達への長期的な害は確認されているか

### 12か月後

同じ2016年RCTでは、介入12か月後に、

- 情緒・行動上の問題
- secure / insecure attachment

を評価し、群間の明確な差は確認されませんでした。

### 約5年後

別のcluster RCTでは、乳児期の行動的睡眠介入を受けた子どもを6歳まで追跡しました。

225家庭が追跡評価に参加し、

- 情緒・行動
- 睡眠
- psychosocial functioning
- chronic stress
- 親子のclosenness / conflict
- disinhibited attachment
- 保護者の抑うつ・不安・ストレス

などに介入群と対照群の明確な差は確認されませんでした。

これは長期的な重大な害を心配するうえで安心材料です。

一方、元の対象326家庭のうち6歳時点で参加したのは225家庭、69%です。また、一つの介入プログラムの追跡結果です。

したがって、

**研究された行動的睡眠介入で長期的な害は確認されていない**

とは言えますが、

**どのような睡眠トレーニングでも長期的に安全だと証明された**

とは言えません。

## 6か月未満は分けて考える

乳児の睡眠は出生後数か月で大きく変化します。

2020年のsystematic reviewでは、6か月未満の介入効果は重要なknowledge gapとして挙げられています。

6か月未満に限定したレビューは結論が一致していません。2013年のsystematic reviewは、集団全体への行動的睡眠介入が母子の主要アウトカムを改善するという十分な証拠を確認できず、意図しない影響の可能性にも注意を促しました。一方、2016年のreviewは11研究を抽出し、そのうち8研究で教育的・行動的プログラム後の乳児睡眠の改善を報告し、「simple, prescriptive behavioral techniques」の有効性を支持しました。

この食い違いは、対象とする介入、アウトカム、研究の選び方が同一ではないことも反映しています。その後の2020年reviewがなお6か月未満をknowledge gapとしていることを踏まえ、このReviewでは「6か月未満には効果がない」とも「6か月以降と同様に確立している」とも断定しません。

このため、今回の中心的な有効性の結論は主に**生後6か月以降で、持続する寝つき・夜間覚醒の問題がある乳児**についてのものです。

新生児や月齢の低い乳児に、同じ方法・同じ目標を機械的に当てはめる根拠はありません。

## 保護者への効果

乳児の睡眠問題は、保護者の睡眠や気分とも関係します。

2023年の13 RCTをまとめたmeta-analysisでは、心理社会的な睡眠介入によって夜間睡眠と母親の抑うつ指標が改善しました。

2025年のsystematic reviewでも、母親のメンタルヘルスやparenting confidenceの改善が報告されています。

ただし介入内容はさまざまで、睡眠トレーニング単独の効果と、支援・教育・相談を受ける効果を完全には分離できません。

## 安全な睡眠環境は別に守る

睡眠トレーニングを検討するとき、最も混同してはいけない点です。

こども家庭庁は、1歳未満について、

> 寝かせる時は、あおむけに寝かせる

ことを案内しています。

AAPの2022年safe sleep policyでも、

- あおむけ
- firm / flat / noninclinedな睡眠面
- bed sharingをせずroom sharing
- 柔らかい寝具や過熱を避ける

などを勧めています。

これらはSIDSや睡眠中の死亡リスクを減らすための安全指針であり、睡眠トレーニングの効果とは別の証拠です。

「一人で寝る練習をさせたい」「寝返りしにくい方が寝る」などの理由で、安全な睡眠環境を崩すべきではありません。

## 日本ではどう考えるか

今回の調査では、日本の公的機関による「睡眠トレーニングの標準手順」は確認できませんでした。

そのため、

- 効果・長期追跡: 主に海外のRCT / systematic review
- SIDS / 安全な睡眠: 日本のこども家庭庁の公的指針

という形で根拠の直接性が異なります。

家庭文化、添い寝の習慣、住環境、授乳方法なども海外研究と異なるため、「海外で効果があった方法」をそのまま日本の全家庭へ当てはめることはしません。

## 家庭ではどう考えるか

研究からは、次のように整理できます。

- 生後6か月以降で、寝つき・夜間覚醒が持続して家族の負担になっている場合、行動的な方法を試す選択肢はある
- 一つの方法だけが正解という証拠はない
- 「泣かせる方法」が唯一の選択肢ではない
- 効果の目標は、睡眠時間を大幅に増やすことより、寝つきや夜間の対応を改善することかもしれない
- 家族が心理的に続けられない方法を無理に選ぶ必要はない
- 6か月未満は同じ証拠を当てはめない
- 安全な睡眠環境は維持する

強いいびき、呼吸が止まるように見える、体重増加や授乳に問題がある、痛みや疾患が疑われるなどの場合は、一般的な行動的睡眠介入だけで判断せず、医療的な評価を優先します。

## Evidence status by claim

| Claim | Current status | Main reason |
|---|---|---|
| 6か月以降の行動的睡眠介入は短期的に寝つき・夜間覚醒を改善する | Supported with heterogeneity | 複数systematic review / RCTが同方向 |
| 睡眠トレーニングは総睡眠時間を大幅に増やす | Not supported as large average effect | 32 RCT meta-analysisで夜間睡眠の平均増加は約9分 |
| graduated extinction等は必ずコルチゾールを増やす | Not supported by small RCT | N=43 RCTでは増加せず。ただし小規模 |
| 適切な行動的介入は長期的に情緒・愛着を悪化させる | Not supported by available follow-up evidence | 12か月・6歳追跡で明確なharm signalなし |
| 6か月未満にも6か月以降と同じ効果がある | Mixed / insufficient for extension | 2013・2016 reviewで結論が異なり、2020 reviewもknowledge gapとする |
| 最も優れた一つの方法がある | Not established | intervention heterogeneity / component attribution |
| 睡眠トレーニングのため安全睡眠指針を緩めてよい | Not supported | SIDS / safe-sleep guidanceが別に優先 |
| 保護者の気分・負担も改善する | Partially supported | meta-analysisで改善報告、介入異質性あり |
