# Q004 — 睡眠トレーニングには効果があり、長期的な悪影響はあるか

Status: REVIEW

Last evidence search: 2026-09-23
Last source verification: 2026-09-23

## Review question

乳児の寝つき・夜間覚醒などの行動性睡眠問題に対する行動的な睡眠介入は、睡眠を改善するか。また、ストレス、情緒・行動、親子関係・愛着などの長期的な悪影響は確認されているか。

## Scope

- Population:
  - 主対象: 生後6〜18か月程度の乳児
  - 6か月未満は別Claimとして扱う
- Intervention:
  - graduated extinction / controlled crying
  - bedtime fading
  - camping out / checking-in
  - consistent bedtime routines
  - broader psychosocial / behavioral sleep interventions
- Comparators:
  - sleep education
  - usual care
  - waitlist / control
- Sleep outcomes:
  - sleep onset latency
  - night waking
  - wake after sleep onset
  - longest continuous sleep period
  - nocturnal / 24-hour sleep duration
- Safety / developmental outcomes:
  - infant cortisol / stress
  - emotional and behavioral outcomes
  - attachment / parent-child relationship
  - longer-term psychosocial outcomes
- Parent outcomes:
  - parental stress
  - maternal mood / depression
- Separate safety boundary:
  - SIDS / sleep-related death prevention
  - sleep position and sleep environment

## Bottom line

生後6か月以降の行動性睡眠問題に対する行動的介入は、**寝つき、夜間覚醒、連続して眠る時間などを短期的に改善する可能性がある**。近年のsystematic reviewでも、効果は全体として小〜中程度で、研究・介入間のばらつきが大きい。

一方、睡眠時間そのものが大幅に増えるとは限らない。0〜5歳のRCTを統合した2021年のメタ分析では、夜間睡眠時間の平均増加は約9分/夜だった。したがって、「睡眠トレーニングをすれば乳児が何時間も長く眠る」と一般化する根拠はない。

graduated extinction と bedtime fading を比較した小規模RCTでは、睡眠指標が改善し、唾液コルチゾール増加は確認されず、12か月後の情緒・行動や愛着にも群間差は確認されなかった。また別の行動的睡眠介入の5年追跡でも、6歳時の情緒・行動、親子関係、ストレスなどに明確な悪影響は確認されなかった。

ただし、**「悪影響が確認されなかった」ことと「あらゆる睡眠トレーニングが安全だと証明された」ことは同じではない。** 安全性研究は数が限られ、方法も一様ではない。

6か月未満については証拠が弱く、2020年のsystematic reviewでも重要なknowledge gapとされている。このReviewでは、6か月未満に同じ結論を広げない。

さらに、睡眠トレーニングの効果とSIDS・窒息等を減らすための安全な睡眠環境は別の問題である。**あおむけ、適切な睡眠面などの安全指針は、睡眠トレーニングの都合で変更しない。**

## Claim status

- C001: 生後6か月以降の行動的睡眠介入は、寝つき・夜間覚醒などを短期的に改善する
  - Status: SUPPORTED_SHORT_TERM_WITH_HETEROGENEITY
- C002: 睡眠トレーニングは乳児の総睡眠時間を大幅に増やす
  - Status: NOT_SUPPORTED_AS_LARGE_AVERAGE_EFFECT
- C003: graduated extinction / bedtime fading は乳児の生理的ストレスを増やす
  - Status: NOT_SUPPORTED_BY_SMALL_RCT / EVIDENCE_LIMITED
- C004: 適切な行動的睡眠介入は長期的な情緒・行動・愛着の悪化を引き起こす
  - Status: NOT_SUPPORTED_BY_AVAILABLE_FOLLOWUP_EVIDENCE
- C005: 6か月未満でも同様に有効である
  - Status: INSUFFICIENT_EVIDENCE
- C006: どの睡眠トレーニング法が最も優れているか
  - Status: NOT_ESTABLISHED
- C007: 睡眠トレーニングのためなら安全な睡眠環境の指針を緩めてもよい
  - Status: NOT_SUPPORTED
- C008: 行動的睡眠介入は保護者の気分や負担も改善しうる

## Review boundary

このReviewはsystematic reviewではない。

2020、2023、2024、2025年のsystematic review / meta-analysisを主要anchorとし、代表的RCT・長期追跡・日本と米国の安全な睡眠指針をtargeted updateで確認した。

独自のdatabase export、deduplication、二重screeningは実施していないためsystematic reviewとは扱わない。主要数値・主要解釈のsource verificationは完了し、現在は公開判定の独立確認待ちとしてREVIEWとする。
