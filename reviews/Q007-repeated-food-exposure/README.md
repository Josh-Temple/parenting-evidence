# Q007 — 同じ食材を繰り返し出すと、食べられるようになるか

Status: REVIEW  
Last searched: 2026-09-24

Publication status: REVIEW; independent publication review completed 2026-09-25; Publication Gate pending

## Review question

同じ野菜へのrepeated taste exposureは、離乳開始後から就学前の子どもで、その野菜へのacceptance / liking / intakeを増やすか。

## Scope

Primary population:
- 4か月〜6歳
- site-facing focus: 主に離乳開始後〜就学前
- typical picky eating / food neophobiaを含む

Primary intervention:
- 同じtarget food、主に野菜を複数回、実際に味わう機会を作るrepeated taste exposure

Secondary:
- different vegetableへのgeneralization
- non-taste familiarization
- repeated exposure + non-food reinforcement

Outcomesは以下を分ける。
1. willingness to taste
2. liking
3. actual intake
4. different unexposed foodへのgeneralization
5. persistence
6. overall picky eating / diet variety / nutritional adequacy / growth

PFD / ARFIDなど、医療・栄養・摂食技能・心理社会面の機能障害を伴う状態は別のclinical boundaryとして扱う。

## Claim map

- C001: target vegetableへのrepeated taste exposureはtarget-food acceptance / intakeを増やす
- C002a: 4〜24か月ではdifferent vegetableへのgeneralizationが支持される
- C002b: 2〜6歳ではdifferent vegetableへのgeneralizationは限定的
- C002c: overall diet / picky eating / nutritional adequacy / growthへの一般化は確立していない
- C003: universalな最適回数・頻度は確立していない
- C004: 2〜6歳のnon-taste exposureはwillingness to tryを高める可能性がある
- C005: positive non-food reinforcementの追加効果はstrategy-specificで、一般推奨にはできない
- C006: repeated exposure単独がpicky eating全体を治療するとは確立していない
- C007: PFD / ARFID等のclinical feeding problemsは通常のpicky eatingと分ける
