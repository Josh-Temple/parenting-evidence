# スクリーン時間は幼児の言語発達に悪いのか

Status: PUBLISHED  
Last searched: 2026-09-23  
Last source verification: 2026-09-23  
Last independent publication review: 2026-09-23

## 30秒で分かる結論

スクリーンを見る時間が長い子どもほど、平均すると言語・コミュニケーション能力がやや低いという関連は、複数の研究で比較的一貫しています。

ただし、影響の大きさは一般に小さく、すべてのスクリーン利用が同じではありません。保護者と一緒に見て会話する使い方は、受動的・単独の長時間視聴とは異なる結果を示します。教育的な内容については良好な関連を報告する研究もありますが、近年のメタ分析では明確な関連が確認されない結果もあり、一律に「教育的なら有利」とは言えません。

また、日本の大規模縦断研究では、スクリーン時間が長いことが後のコミュニケーション得点の低下を予測した一方、コミュニケーション得点が低いことも後のスクリーン時間増加を予測しました。

したがって、研究だけから個々の家庭に一律の削減量を決めることはできませんが、長時間・非教育的・単独の利用を抑え、会話・遊び・睡眠などを確保する方向は現在の小児科・公衆衛生ガイダンスと整合します。「1日○分を超えると必ず言葉が遅れる」といった単純な因果関係や正確な安全閾値は確認されていません。

## 研究で最も一貫していること

### 1. スクリーン時間が長いほど、言語能力は平均して少し低い

2020年のsystematic review / meta-analysisは42研究、18,905人を統合しました。

スクリーン利用時間と言語能力の関連は、

- screen time: r=-0.14
- background television: r=-0.19

でした。

どちらも大きな関連ではありませんが、平均するとスクリーン利用が長いほど言語能力が低い方向です。

一方、研究間のばらつきは大きく、スクリーンの種類、家庭環境、子どもの年齢、測定方法などが異なります。

## 「何を見るか」「誰と見るか」も重要

同じ2020年のメタ分析では、

- educational programming: r=0.13
- caregiverとのco-viewing: r=0.16

と、より良い言語能力との正の関連が報告されました。

ただし、その後の研究は「教育的内容」と「共同利用」を同じ強さで支持しているわけではありません。2023年の語彙学習メタ分析（63研究、11,413人）では、実験研究ではスクリーンからの特定語彙学習に平均的な正の効果があり、自然な家庭利用でも教育的メディアは語彙と正の関連を示しました。一方、2024年の0〜3歳を対象とした28研究のメタ分析では、共同視聴と遅い利用開始は良好な言語アウトカムと関連したものの、教育的番組と言語発達の関連は統計的に明確ではありませんでした。

また、2024年の100研究、176,742人を含む別のsystematic reviewでは、単純な利用時間だけでなく利用文脈を調べています。program viewingやbackground TVは認知アウトカムと負の関連を示し、co-useは正の関連を示しました。ここでいうprogram viewing全体と「教育的内容」は同じ概念ではありません。

このため、「動画を1時間見た」という情報だけでは十分ではありません。

- 内容は年齢に合っているか
- 一人で見ているか
- 大人と話しながら見ているか
- TVが背景でついているだけか
- 本来の会話・遊び・睡眠を置き換えているか

まで考える必要があります。

## 日本の大規模研究では、関係は一方向ではなかった

Japan Environment and Children's Studyは57,980人を対象に、1〜3歳のTV/DVD視聴時間と発達を縦断的に解析しました。

1歳時点のスクリーン時間が長いことは、2歳時点のコミュニケーション得点の低下を予測しました。

- screen time age 1 -> communication age 2: beta=-0.06

2歳から3歳についても、より小さいながら同じ方向の関連がありました。

しかし逆方向も確認されています。

- communication age 1 -> screen time age 2: gamma=-0.03
- communication age 2 -> screen time age 3: gamma=-0.06

つまり、

> スクリーンを見るからコミュニケーション発達が弱くなる

だけではなく、

> コミュニケーションが難しい子どもほど、その後スクリーン利用が増える

可能性もあります。

この研究は通常の単純な相関研究より時間方向を詳しく検討していますが、観察研究なので因果関係を確定するものではありません。

## なぜ関係する可能性があるのか

一つの候補が、親子で話す機会の置き換えです。

オーストラリアの220家庭を12〜36か月まで追跡し、家庭内の音声を繰り返し測定した2024年の研究では、スクリーン時間が長いほど、

- 大人が子どもに話す言葉
- 子どもの発声
- 親子の会話の往復

が少ない傾向がありました。

36か月時点では、スクリーン時間が1分増えることと、

- adult words 6.6語減少
- child vocalizations 4.9回減少
- conversational turns 1.1回減少

が関連していました。

これは、スクリーンが言語発達へ影響しうる仕組みとして「会話機会を置き換える」という説明と整合します。

ただし、この数字を「動画1分が必ず6.6語を奪う」という因果効果として扱ってはいけません。研究は観察研究です。

## スマホ・タブレットなら安全という証拠はない

デンマークの2〜3歳児31,125人の調査では、モバイル端末を1日1時間以上使うことが、言語理解・表出言語の困難と関連していました。

2時間以上では、ほとんど使わない群と比較して、

- language comprehension difficulty: adjusted odds ratio 1.42
- expressive language difficulty: adjusted odds ratio 1.46

でした。

ただし横断研究なので、「端末利用が困難を生んだ」とは判断できません。

端末の種類だけで安全性を判断するより、時間・内容・共同利用・家庭で何を置き換えているかを見る方が研究全体と整合します。

## 長期的な関連も報告されている

ニュージーランドの6,281人を追跡した研究では、2〜4.5歳のスクリーン曝露が多いほど、その後の語彙、コミュニケーション、初期学習能力が低い傾向がありました。

家庭の社会的背景を調整すると関連は弱くなりましたが、残りました。

研究では2歳時点で1日1.5時間を超える群に不利な結果が報告されています。しかし、これは「1時間29分なら安全で、1時間31分なら有害」という意味ではありません。観察研究上のカテゴリーであり、生物学的な閾値ではありません。

## では、1日何時間までなのか

### 言語発達だけから正確な上限は決められない

研究から「万人に共通する言語発達上の安全閾値」は確認できませんでした。

数値の目安が必要な場合、WHOの2019年のunder-5 movement guidelineでは、sedentary screen timeについて、

- 1歳: 推奨しない
- 2歳: 1時間以内、少ないほどよい
- 3〜4歳: 1時間以内、少ないほどよい

としています。

ただし、これは言語だけでなく身体活動、座位行動、睡眠を統合した健康ガイドラインです。

### AAPの現在の考え方は「時間だけ」から広がっている

American Academy of Pediatricsは2026年に旧media guidanceを改訂しました。

現在は、screen timeだけを唯一の基準にせず、

- quantity
- content
- device / media type
- joint media engagement
- interactivity
- 子ども・家庭を取り巻く環境

を含めて考える方針です。

幼児については、重い非教育的・単独利用は言語等の発達遅延と関連する一方、高品質の教育コンテンツや大人とのjoint media engagementはより良い学習・言語アウトカムと関連すると整理しています。

## 家庭ではどう考えるか

研究全体からは、「ゼロか100か」より次の考え方の方が妥当です。

### 優先したいこと

- 食事、遊び、読み聞かせ、会話など、親子で直接やり取りする時間を確保する
- TVを見ていないときは背景でつけっぱなしにしない
- 幼い子が見る場合は、年齢に合った内容を選ぶ
- 可能なら一緒に見て、画面で起きていることを話す
- 睡眠や運動、外遊びを継続的に押しのけるほど長時間になっていないかを見る

### 必要以上に罪悪感を持たなくてよいこと

今回確認した研究からは、短時間のスクリーン利用が子どもの言語を直ちに害するとは言えません。

効果量は一般に小さく、家庭環境との交絡もあります。現在のAAPも、家族ごとの事情を無視した単純な時間管理だけでは不十分だとしています。

重要なのは、「何分だったか」だけでなく、スクリーンによって**何が置き換えられたか**です。

## 言葉が遅い場合

言語発達が心配な場合、「スクリーンを見せたから」と原因を決めつけるべきではありません。

日本の縦断研究でも逆方向の関連が確認されています。

スクリーン時間の調整は家庭環境の一部として考えられますが、明らかな言語・コミュニケーションの心配がある場合、このReviewだけで原因判断や発達評価を置き換えないでください。

## Evidence status by claim

| Claim | Current status | Main reason |
|---|---|---|
| 長いスクリーン時間と言語能力低下には関連がある | Supported as small association | 言語特化meta-analysisと複数の大規模・縦断研究が同方向 |
| screen time自体が言語遅延を引き起こす | Plausible but not established | 時間方向・機序の証拠はあるがrandomized causal evidenceが不足 |
| 共同利用・共同視聴はより良い言語アウトカムと関連する | Supported as context dependent | 2020言語meta-analysis、2024年0〜3歳meta-analysis、2024 context meta-analysisが概ね同方向 |
| 教育的内容は言語発達に有利 | Mixed / uncertain | 2020・2023 meta-analysisは良好な関連を示す一方、2024年0〜3歳meta-analysisでは明確な関連なし |
| screen useは親子の会話を減らしうる | Supported as plausible mechanism | repeated home audio measurement |
| 1日○時間という言語上の安全閾値がある | Not established | cohort cutoffsとguideline limitsは因果的thresholdではない |
| 言語発達の弱さがscreen time増加につながることもある | Supported | JECS cross-lagged analysis |
