# Q003 — タイムアウトは幼児の問題行動に有効か

Status: REVIEW

Last evidence search: 2026-09-22
Last source verification: 2026-09-23

## Review question

幼児〜就学前児の反抗・攻撃・危険行動などに対し、time-out from positive reinforcement（以下「タイムアウト」）は問題行動を減らすのに有効か。また、適切に実施した場合の長期的な害は確認されているか。

## Scope

- Population: 主に2〜6歳。必要に応じて2〜12歳の親訓練研究を補助的に使用
- Intervention:
  - time-out as an isolated behavioral procedure
  - time-out as one component of behavioral parent training / parent management training
- Comparator:
  - no treatment / waitlist / usual care
  - alternative parenting strategies
  - parent training without clear component isolation
- Primary outcomes:
  - noncompliance
  - disruptive / conduct behavior
  - aggression / unsafe behavior
- Safety outcomes:
  - emotional / behavioral functioning
  - parent-child relationship / attachment
  - adverse events
- Implementation dimensions:
  - indication / target behavior
  - warning and predictability
  - duration
  - caregiver affect
  - isolation / safety
  - consistency
  - use of positive reinforcement outside time-out

## Bottom line

行動療法に基づく親訓練プログラムは、幼児〜小学生の問題行動を短期的に減らすことが複数のRCT・メタ分析で確認されている。タイムアウトはその多くに含まれる代表的な非暴力的な限界設定技法である。

一方で、**親訓練プログラム全体が有効であることと、タイムアウト単独の因果効果は同じではない。** タイムアウトそのものを他の技法から切り離して比較した高品質な現代RCTは少なく、単独効果の大きさは十分に確定していない。

単一の養育行動を実験的に操作した2018年のmultilevel meta-analysis、2008年の親訓練component meta-analysis、臨床研究は、タイムアウトが特定の非従順を減らしうることを支持する。一方、2019年のより大規模なcomponent meta-analysisでは、タイムアウトは独立した「強い効果を持つ構成要素」としては抽出されず、positive reinforcement、praise、natural/logical consequencesがより一貫して強い効果と関連した。

したがって、現時点では、**タイムアウトは万能な罰ではなく、正の強化・明確な指示・一貫したルールを中心とする親訓練の一部として、特定の危険・攻撃・ルール違反・指示不従順に限定して短く穏やかに使う場合には、有効な選択肢になりうる**と整理するのが妥当である。

適切に使われたタイムアウトが長期的な情緒・行動・親子関係を悪化させるという証拠は、現在確認できない。ただし「害がないことが完全に証明された」という意味ではなく、安全性研究の多くは観察研究である。

  - Status: SUPPORTED

  - Status: PLAUSIBLE_BUT_COMPONENT_ATTRIBUTION_LIMITED
- C003: タイムアウトは非従順などの直後の標的行動を減らしうる

  - Status: SUPPORTED

  - Status: NOT_SUPPORTED_AS_GENERAL_RULE

## Review boundary

このReviewはsystematic reviewではない。

タイムアウト単独を対象にした現代の包括的systematic reviewは確認できず、以下を組み合わせて評価した。

1. behavioral parenting programs全体のRCT meta-analysis
2. parenting-program component meta-analysis
3. time-outを直接扱う実験・臨床研究
4. attachment / long-term harmに関する縦断・観察研究
5. CDC / AAP等の現行guidance

そのため、親訓練全体の効果をタイムアウト単独へ帰属させない。
