## Review question

親が乳幼児の前でスマートフォン・タブレット・PC等を使うことは、親子相互作用や子どもの発達とどのように関連するか。

## Scope

Primary population:
- birth–5.99 years
- infant-specific evidenceは0–24か月を別に扱う

Exposureは caregiver technology use in the child's presence とし、以下を分ける。
- ordinary use duration
- interaction interruption / distraction / technoference
- problematic / compulsive use
- device type
- play / meal / feeding / routine care等のcontext
- intentional co-use と caregiver-only use

Q002の child screen exposure とは別Reviewとして扱う。

## Claim map

- C001: caregiver technology useは一部の認知・心理社会的outcomeと小さく関連する
- C002: caregiver technology use自体が長期発達の不利益を引き起こす
- C003: active smartphone interruptionはその場のcaregiver-child interactionを低下させる
- C004: caregiver technoferenceは後のchild screen / problematic media useと関連する
- C005: universal daily safety thresholdが存在する
- C006: reverse causation / shared family stressが観察関連に関与する
- C007: caregiver screen minutesが多いほどinteraction qualityが必ず低い
- C008: caregiver technoferenceが言語発達を一貫して悪化させる
