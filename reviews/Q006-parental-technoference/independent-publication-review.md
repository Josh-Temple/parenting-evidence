## Scope

Publication Gateに従い、bottom line、主要effect estimate、比較条件、因果表現、安全性・閾値表現、年齢範囲、日本への適用、current guidance、anchor以後のupdate evidenceを独立に再構成した。

## Independent bottom line

現在の証拠は、次の狭い結論を支持する。

1. standardized smartphone interruptionは、少数の短期実験で母親の応答性・感受性や乳児のaffectをその場で悪化させうる。
2. caregiver technology use / technoferenceと一部の認知・心理社会的outcomeには小さなassociationがあるが、観察研究中心でheterogeneityがあり、outcomeごとに結果が異なる。
3. caregiver technology use自体が長期発達の不利益を引き起こす因果効果は確立していない。
4. parental technoferenceと後のchild problematic media useにはlongitudinal associationがあるが、shared family factorsやcommon reporterを除けない。
5. 親についてのuniversal daily safety thresholdは確立していない。
6. parenting stress・child behavior・technology interferenceには双方向性を示唆する縦断証拠があり、親→子の一方向モデルに限定しない。
7. language outcomeは一貫していない。motor / selected executive-function outcomeには2026 SUNRISEのnull evidenceもある。

## Claim reconstruction

### C001 — selected cognitive / psychosocial associations

Decision: PASS_WITH_CONTEXT

Independent reconstruction:
- Toledo-Vargas 2025 meta-analysisはcognition r=-0.14、internalizing/emotions r=0.13、externalizing r=0.15、prosocial r=-0.08、attachment r=-0.10、child screen time r=0.23のsmall associationsを報告。
- languageは r=-0.09, 95% CI -0.31 to 0.14でnon-significant。
- anchor reviewではmotor developmentの研究がなかった。
- 2026 SUNRISEでは27か国、N=2,232でcaregiver smartphone-use frequencyとgross/fine motor、visual-spatial working memory、inhibitionに調整後の有意な関連なし。

Difference from existing Review:
SUNRISEはC007のinteraction-quality claimではなく、C001のoutcome-specific null evidenceとして位置づけ直す。

### C002 — long-term causal developmental harm

Decision: PASS

Independent reconstruction:
observational association、短期experiment、longitudinal associationは存在するが、caregiver technology use自体の長期因果効果を隔離していない。

### C003 — acute interaction disruption

Decision: PASS

Independent reconstruction:
Mikić 2025は52 mother-infant dyads、5–6か月でcounterbalanced free-play / interruptionを比較し、interruption時のmaternal sensitivity / responsiveness低下とinfant affect変化を報告。2026 infant systematic reviewも16 studiesで短期dyadic disruptionをまとめるがheterogeneous / preliminary。

Boundary:
long-term developmental harmへ一般化しない。

### C004 — later child media use

Decision: PASS

Independent reconstruction:
Ashby 2026はN=500、6か月→6.5歳でinitial maternal technoferenceとPMU age 6.5のassociation β=0.48, p<.001。maternal reportが両側に使われ、shared factorsを除けない。

### C005 — universal safe daily threshold

Decision: PASS

Independent reconstruction:
JECSの<1h / 1–<2h / >=2hはobservational categoriesでありcausal safety boundaryではない。targeted official-source searchで日本の全国一律のcaregiver-device-use cutoffは確認できていない。

### C006 — bidirectionality / shared stress

Decision: CHANGE REQUIRED → APPLIED

Independent reconstruction:
McDaniel & Radesky 2018は183 couples、young child 0–5y、baseline / 1 / 3 / 6 monthsのcross-lagged study。child externalizing → parenting stress → later technology interferenceと、technology interference → later externalizingの両方向が報告された。

Schneebeli 2025等のcross-sectional evidenceだけでchild→parentの時間方向を示すより、この縦断研究をC006の直接証拠として追加する方が適切。

Applied change:
B1としてevidence-table / review / source-verification / search-strategyへ追加。

### C007 — raw amount and observed interaction quality

Decision: CHANGE REQUIRED → APPLIED

Independent reconstruction:
Ventura 2025はN=147でpassive sensing + EMAによるtypical smartphone useと別時点のfeeding observationを組み合わせ、typical amount / perceived technoferenceとobserved interaction qualityにsignificant associationを認めなかった。ただしスマホ利用とfeeding interactionを同時測定しておらず、active interruption evidenceを反証しない。

Applied change:
SUNRISEはinteraction qualityを測定していないためC007から外し、C001のmotor/executive-function null evidenceへ移した。

### C008 — consistent language harm

Decision: PASS

Independent reconstruction:
A1 pooled language estimateはnon-significant。JECSはlanguage-social associationを報告。Coyne 2026はconcurrent associationはあるがlongitudinal technoference predictionは有意でない。MIXED / NOT ESTABLISHEDが妥当。

## Japan applicability

PASS_WITH_LIMITATION.

- JECSは日本固有の直接証拠だがobservational、maternal self-report exposure。
- 1h/2h categoryはnational recommendationではない。
- こども家庭庁の現行資料は主にchildren's device use / internet safety / family rulesを扱う。今回のtargeted official-source searchではcaregiver device use while with infants/young childrenについて全国一律の時間基準は確認できなかった。
- 「確認できなかった」は不存在証明ではない。

## Current guidance

AAP 2026 Digital Ecosystems policy / technical reportをcurrent professional guidanceとして確認。

- digital ecosystemをchild screen limitsだけで捉えない。
- frequent digital disruptions of caregiver-child interaction (technoference) can be associated with behavioral challenges。
- caregiver stress is associated with greater caregiver mobile-device use。
- providers are advised to ask about caregiver and child digital media use and encourage caregivers to model healthy habits。

Research effect estimateやcausal thresholdの根拠とは分離する。
