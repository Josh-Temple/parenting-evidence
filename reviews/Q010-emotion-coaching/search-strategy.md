# Q010 Search Strategy

Last searched: 2026-09-26

## Review type

Targeted evidence review. This is **not** a de novo systematic review.

Primary quantitative anchor:
- England-Mason et al. 2023 RCT systematic review/meta-analysis

Update horizon:
- through 2026-09-26

## Question decomposition

Population:
- parents/caregivers of children 18 months–6 years 11 months

Primary intervention:
- emotion-socialization / emotion-coaching parenting program packages

Keep separate:
- single emotion-labeling phrase
- ordinary behavioral parenting program
- attachment intervention
- child-only SEL
- parent mental-health treatment
- clinical/severe treatment populations

Outcomes:
- parent emotion coaching/dismissing
- parent emotion regulation
- positive/negative parenting
- child emotional competence
- child behavior adjustment
- parent psychological well-being

## Search streams

1. RCT systematic review/meta-analysis
2. direct TIK / emotion-socialization trials
3. toddler interventions
4. cross-cultural RCTs
5. post-2022 updates
6. comparator strength / active control
7. developer/research-team independence
8. Japan-specific intervention/context evidence

No new evidence identified in this targeted pass that changes the primary claim structure.

A 2025–2026 Daily Growth emotion-coaching trial is currently represented by protocol-level evidence and is not treated as outcome evidence before results are available.

## Inclusion principles

Include:
- randomized emotion-socialization parenting interventions
- child age within primary scope
- cross-cultural direct trials
- mixed/null update evidence
- observational Japan context only with explicit noncausal label

Do not convert:
- package effect → single phrase/component effect
- waitlist effect → superiority over active parenting program
- Chinese/Hong Kong evidence → Japanese replication
- paper count → independent research-team count

## Search limitations

- no database-native full export
- no dual screening
- no project-wide formal risk-of-bias tool
- direct Japan intervention RCT not identified in targeted search
- evidence network contains substantial TIK/developer concentration
- active-comparator evidence is limited
